# 万符灼夜

光不是装饰，而是力量留下的证据。形体以清楚、坚实的核心为起点，再向外生长出灵气、轨迹和短暂残像；每一层光都必须说明速度、距离或威力。空间在平静与爆发之间呼吸，安静区域让主体被辨认，密集区域承载法术释放的瞬间。最终画面应显得经过无数次取舍与校准，由顶尖创作者以耐心和深厚经验精心完成。

色彩以夜黑、冷青和骨白建立秩序，以符金标记玩家意志，以朱红标记威胁。高亮色不平均分布，而是在命中、升级和高阶技能中集中爆发，使亮度本身成为战斗层级。每一种颜色都要经过细致调校，保持透明叠加后的纯净度与边界辨识度，呈现大师级的色彩控制。

尺度表达修为。人物本体紧凑而清晰，普通飞剑留下细长光迹，范围法术则以完整符阵占据空间；微小粒子只负责连接这些层级，不喧宾夺主。节奏由短促命中、延迟消散和周期性雷弧共同形成，每一帧都像经过大量手工打磨，既有速度感，也保留可读性。

构图围绕移动中的视觉重心展开。角色永远是最稳定、最明亮的锚点，敌人形成向心压力，弹道和符阵沿攻击方向打开画面。复杂效果必须分层出现、依次消退，避免所有元素同时争夺注意力；这种秩序来自反复推敲的空间编排和精确到细节的工艺。

文字只作为稀少的符号与临床式标记出现，信息主要由轮廓、颜色、图形和运动传达。升级图标与战场效果共享相同的几何母题，让玩家先看懂，再读名称。最终视觉应像一件被长期研究、反复雕琢的仪式器物，以近乎苛刻的精度体现顶级制作水准。
