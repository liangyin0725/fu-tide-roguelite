# 流派组合技系统设计

## 目标

让现有 10 个技能与强化产生构筑关系。组合技不占槽位；组成能力均已装备且至少 Lv.1 时自动激活。

## 六个组合技

1. 雷狱共鸣（护身雷环 + 五雷连引）：每秒从雷环内目标额外连锁两名敌人。
2. 冰火劫（爆炎符 + 玄冰符）：对减速或冻结目标触发爆炎时，伤害提高 50%，范围增加 25。
3. 万剑护阵（绕身剑轮 + 破魔真炁）：剑轮形成连续挡弹环，破弹反击伤害提高 50%。
4. 星火坠世（天火陨印 + 北斗星芒）：每枚天火命中后向四方发射星芒。
5. 不灭回响（金光护体 + 聚灵玉）：施放主动技能额外恢复 25% 最大护盾，并使本次冷却缩短 20%。
6. 镇魂斩劫（地煞钉魂 + 斩劫诀）：钉魂对劫主触发率提高 8%，触发时追加两倍飞剑伤害。

## 表现与界面

- HUD 在技能栏上方显示已激活组合技短标签。
- 升级或宝箱选择将组成能力时，卡片显示即将激活的组合技。
- 每次组合技产生关键效果时发送 `synergy-triggered` 战斗事件，由特效和音频统一消费。
