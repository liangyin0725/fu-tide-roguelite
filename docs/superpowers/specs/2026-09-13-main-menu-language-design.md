# 主界面双语切换设计

## 目标

在《符潮残夜》主界面加入简体中文和 English 切换按钮。语言偏好持久化到现有游戏设置，切换后即时刷新 UI，不影响战斗模拟、局外存档或数值。

## 交互

- 主菜单的操作按钮下方放置紧凑的 `中文 / EN` 分段控件。
- 默认语言为简体中文；选择 English 后刷新页面仍保持 English。
- 设置面板不重复放置语言项。

## 架构

- `GameSettings` 新增 `language: 'zh-CN' | 'en'`，旧设置自动补为 `zh-CN`。
- `src/i18n/uiText.ts` 提供静态文案、角色名、升级名、天劫名和常用动作的翻译函数。
- `HudController` 保留既有状态/数值渲染，只从翻译模块获取显示文本。战斗逻辑不读取语言设置。

## 覆盖范围

- 主菜单、设置、角色选择、升级、宝箱、觉醒、天劫、洞府、内测页和局末总结。
- 技能、强化、角色、遗物、天劫和常见状态名称显示英文。

## 验证

- 设置迁移测试验证旧存档默认中文且英文可持久化。
- HUD 测试验证主菜单按钮触发 `language` 设置更新，并在英文模式显示英文主操作。
- 全量 Vitest 与 Vite 构建必须通过。
