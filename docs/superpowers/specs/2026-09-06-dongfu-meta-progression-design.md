# 洞府局外成长设计

## 目标

为《符潮残夜》增加可跨局保存的轻量成长线。玩家击败劫主后获得道蕴，并在主菜单的洞府中解锁角色专属天赋。局内的技能、升级、宝箱和角色选择规则保持不变。

## 范围

- 新增浏览器本地洞府存档，独立于现有游戏设置存档。
- 新增道蕴货币与劫主击败奖励。
- 新增主菜单洞府入口、洞府面板与九项角色天赋。
- 新局开始后，在角色选择完成时把已解锁天赋应用到该局角色。
- 不加入云同步、重置存档按钮、随机词条、局外装备或付费货币。

## 数据与保存

新建 `metaProgression` 模块，使用单独的 `fu-tide-dongfu-v1` 本地存档键。

存档结构：

```ts
{
  version: 1,
  daoYun: number,
  unlockedTalentIds: TalentId[]
}
```

- 初始道蕴为 0，初始没有已解锁天赋。
- 无效、损坏或版本不匹配的存档回退为默认值。
- 道蕴永不为负，重复解锁已拥有天赋不会重复扣除道蕴。
- 本期不提供清档入口，避免玩家误删局外进度。

## 奖励规则

- 每击败一位劫主，立即获得 1 点道蕴。
- 奖励发生在劫主的死亡结算中，与宝箱、经验爆发并行，不依赖玩家拾取宝箱。
- 同一劫主只会在死亡结算时奖励一次；重开一局不会重复领取。
- 局末总结显示本局获得的道蕴，主菜单洞府显示总余额。

## 天赋树

每名角色各有一条三层线性路线。只有同路线上一层已解锁时才能解锁下一层；费用依次是 1、2、3 道蕴。角色固有特性仍然保留，局外天赋在固有特性之后计算。

| 角色 | 天赋 | 效果 | 费用 |
| --- | --- | --- | --- |
| 玄剑 | 剑意初凝 | 飞剑伤害 +8% | 1 |
| 玄剑 | 御剑疾行 | 攻击间隔 -8% | 2 |
| 玄剑 | 破界锋芒 | 飞剑穿透 +1 | 3 |
| 雷篆 | 引雷入体 | 术法伤害 +8% | 1 |
| 雷篆 | 雷域扩张 | 雷环与太虚钟范围 +12% | 2 |
| 雷篆 | 灵息回响 | 经验获取 +10% | 3 |
| 守一 | 守元固本 | 最大生命 +10% | 1 |
| 守一 | 玄甲常驻 | 开局获得 20 点护盾 | 2 |
| 守一 | 生生不息 | 生命恢复 +0.6/秒 | 3 |

“术法伤害”覆盖雷环、连锁雷法、爆炎、天火陨印、北斗星芒、日轮剑光、太虚钟、灵泉剑瀑、主动技能和弹幕反击，不影响飞剑与绕身剑轮。

## 局内应用

1. 主菜单打开洞府可解锁天赋，关闭后返回菜单。
2. 玩家开始新局并选定角色。
3. 当前角色的已解锁天赋通过现有 `recalculatePlayerBuild` 流程叠加到基础属性和角色固有特性上。
4. 重开会创建新的局内状态，但重新选择角色后仍应用相同局外进度。

局外效果不会写入升级栏位，因此不会占用五个技能格或六个强化格；也不会出现在局内随机升级选项中。

## UI

- 主菜单新增“洞府”按钮，与“开始渡劫”同级。
- 洞府面板显示道蕴余额，以及三名角色的纵向天赋路线。
- 每个天赋显示名称、效果、费用和状态：未解锁、可解锁、前置未完成、已解锁。
- 可解锁项可点击；余额不足或前置缺失的项不可点击。
- 局末总结在统计区下方显示“本局道蕴 +N”。

## 测试与验收

- 默认、损坏和有效洞府存档的读取与写入。
- 天赋顺序、费用扣除、余额不足、重复解锁不扣费。
- 击败劫主后恰好增加 1 道蕴。
- 三名角色的天赋只影响对应角色，并在新局选择角色后生效。
- HUD 显示洞府入口、余额、锁定状态和本局奖励。
- 全量单元测试、生产构建，以及桌面/移动端洞府面板的视觉检查。
