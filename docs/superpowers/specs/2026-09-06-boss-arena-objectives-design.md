# 劫主战场目标设计

## 目标

让每位劫主的二阶段拥有一个必须处理的战场目标。玩家需要在输出劫主、躲避技能和摧毁目标之间做选择；忽略目标会强化劫主，而不是额外堆叠普通怪物。

## 范围

- 劫主首次进入二阶段时生成一个专属战场目标。
- 三种劫主拥有不同目标、视觉颜色和失败强化。
- 目标成功或失败都会给出明确 HUD、特效、音效和战斗事件。
- 不改变现有五分钟劫主周期、天劫阶段目标、洞府、宝箱选择或角色构筑规则。

## 触发与状态

- 每名劫主只在第一次进入二阶段时生成一次目标。
- 目标在劫主身边 210 到 280 像素处生成，为可受伤、静止的场景实体，并带有 `ownerBossId`。
- 每次最多存在一个劫主战场目标；如果同一时间存在多个劫主，仅最新进入二阶段的劫主触发目标。
- 目标生成后有 22 秒倒计时。劫主死亡时，归属该劫主的未结算目标立即清除且不发放奖励或失败强化。
- 战场目标与既有十分钟天劫目标使用独立状态，不覆盖已有 `activeObjectiveId`。

新增局内状态：

```ts
activeBossObjectiveId: number | null
bossObjectiveExpiresAtMs: number
```

新增实体字段：

```ts
ownerBossId?: number
bossObjectiveKind?: 'crimson-anchor' | 'storm-pylon' | 'blood-well'
bossArenaResolved?: boolean
bossArenaEnraged?: boolean
```

## 三类战场目标

| 劫主 | 目标 | 成功 | 超时失败 |
| --- | --- | --- | --- |
| 赤煞劫主 | 赤煞阵眼 | 劫主 4 秒停滞，承受伤害 +25% 持续 10 秒 | 冲锋路径额外留下两道赤煞封锁线，之后技能范围 +20% |
| 雷狱劫主 | 引雷天柱 | 劫主 4 秒停滞，承受伤害 +25% 持续 10 秒 | 后续雷圈数量 +2，预警时间缩短 20% |
| 血月劫主 | 血祭魔井 | 劫主 4 秒停滞，承受伤害 +25% 持续 10 秒，并清除其回血技能的下一次施放 | 后续血印治疗量提高到最大生命的 7% |

目标生命值为 `320 + 当前劫数 * 130`。目标成功时，玩家获得当前升级需求 50% 的即时经验，额外掉落 6 枚经验碎片；不产生宝箱，避免在劫主战中打断战斗选择流程。

“承受伤害 +25%”为临时劫主专属易伤：只影响归属劫主，不影响普通怪、其他劫主或玩家已有的 `bossDamageMultiplier`。停滞期间劫主移动速度为 0，危险区域仍按既有流程消退但不再开启新的施法。

## 模拟与事件

`GameSimulation` 在二阶段转换处根据 `bossType` 创建目标，并发出：

```ts
{ type: 'boss-objective-spawned'; x; y; bossType; objective; expiresAt }
{ type: 'boss-objective-resolved'; x; y; bossType; objective; success: boolean }
```

目标被击败时结算成功；倒计时到期时结算失败。结算后清空局内目标状态，保留归属劫主的成功易伤或失败强化字段。伤害函数根据成功的易伤窗口和失败强化调整对应劫主的承伤与危险区域配置。

## 呈现

- HUD 在劫主血条下方显示目标名称、倒计时和目标生命条。
- 赤煞使用红金锁链与封锁线预警；雷狱使用青蓝雷柱和地面电弧；血月使用玫红血池与向劫主流动的血线。
- 生成时播放长预警环；成功使用金青爆环；失败使用对应颜色的全屏边缘闪烁与重震屏。
- 设置中的特效强度、伤害数字和屏幕震动继续生效；低特效模式保留目标血条与判定边界。

## 测试与验收

- 二阶段只为对应劫主生成一次、且不覆盖普通天劫目标。
- 三种劫主生成正确目标并使用按劫数缩放的生命值与 22 秒时限。
- 摧毁目标会正确结算停滞、易伤、经验碎片和成功事件。
- 超时会正确标记对应劫主强化并产生失败事件。
- 劫主死亡清除未结算目标且不额外触发结果。
- HUD 显示目标名称、倒计时、生命条；效果规格覆盖生成、成功和失败事件。
- 全量测试、生产构建以及三种劫主预览的视觉检查通过。
