# 觉醒降临设计

## 目标

把六级技能的觉醒从一次数值封顶，提升为一次会立即改变战场的专属降临；觉醒后的持续技能效果继续保留现有强度与机制。

## 范围

- 仅作用于 `SKILL_IDS` 的十三项技能；四级强化沿用既有觉醒流程。
- 每项六级技能触发时在玩家位置释放一次专属降临，并产生命中、控制、弹幕清除或齐射等可见战场结果。
- `skill-awakened` 特效持续 2.3 秒，并按技能属性使用独立颜色、轮廓和光线形状。
- 觉醒面板补充“觉醒降临”说明，明确告知即时效果。
- 不新增依赖，不改变局外成长、升级选择和普通技能等级效果。

## 降临规则

| 技能 | 觉醒降临 |
| --- | --- |
| 雷环 | 以玩家为中心的雷狱震击，伤害近处敌人。 |
| 引雷 | 向最近敌群释放连续雷链。 |
| 爆炎 | 以玩家为中心释放大范围劫火。 |
| 金刚护体 | 立即补满护盾并释放护体震波。 |
| 冰封符 | 大范围冻结普通敌人、重度减速劫主。 |
| 剑轮 | 清除近处弹幕并斩击包围圈。 |
| 陨星印 | 连续召来密集陨星轰击最近敌群。 |
| 北斗星阵 | 立即释放双层星阵齐射。 |
| 破法回响 | 清除近处弹幕并释放反击震波。 |
| 镇魂钉 | 大范围定身普通敌人、减速劫主。 |
| 日轮剑光 | 对最近敌群降下三道日轮剑光。 |
| 太虚钟 | 扩张钟鸣震波并清除范围弹幕。 |
| 灵泉剑瀑 | 向最近敌群密集降下灵剑。 |

## 验收

- 任一六级技能升级后进入觉醒阶段，产生一条 `skill-awakened` 事件和该技能可观察的即时战斗结果。
- 大范围控制、弹幕清除、齐射和伤害行为可由模拟测试验证。
- 觉醒视觉效果在事件规格中持续 2300ms，且渲染按技能类别分型。
- 全部测试与生产构建通过。
