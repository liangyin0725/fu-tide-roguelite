# 无限怪潮与五分钟 Boss 周期设计

## 目标

将 `符潮残夜` 从五分钟生存胜利改为无限生存模式。玩家只在生命归零时结束游戏；每经过五分钟生成一只逐轮增强的 Boss。普通怪保持持续压力，但后期刷新速度设置下限，并在 Boss 登场后的短暂窗口进一步减速。

## 无限计时

移除五分钟胜利判定和 `won` 阶段。`elapsedMs` 持续累计，HUD 主计时显示已生存时间并向上计数。死亡结算继续显示最终等级、击杀数和累计生存时间。

`GameState` 删除 `survivalGoalMs`，增加：

- `nextBossAtMs`：下一只 Boss 的生成时间，初始值为 `300000`。
- `bossWave`：已经生成的 Boss 轮次，初始值为 `0`。
- `bossesDefeated`：已经击败的 Boss 数量，初始值为 `0`。
- `bossSlowdownUntilMs`：Boss 缓冲期结束时间，初始值为 `0`。

HUD 显示累计生存时间和距离下一只 Boss 的倒计时。倒计时在 Boss 生成后重置为五分钟。

## Boss 周期

模拟层每帧在普通怪刷新前检查 Boss 时间。只要 `elapsedMs >= nextBossAtMs`，就生成对应轮次 Boss，并将 `nextBossAtMs` 增加 `300000`。使用 `while` 处理一次更新跨越多个周期的测试或后台恢复情况，确保五分钟节点不丢失也不重复。

Boss 生成不受普通怪数量上限影响。即使上一轮 Boss 仍存活，下一个五分钟节点仍会生成新 Boss。

Boss 使用以下线性成长：

- 轮次 `n` 从 1 开始。
- 最大生命：`600 + (n - 1) * 350`。
- 接触伤害：`20 + (n - 1) * 3`。
- 移动速度：`52 + min(28, (n - 1) * 2)`。
- 经验奖励：`60 + (n - 1) * 20`。
- 碰撞半径：`42`。

`Enemy` 增加 `kind: 'normal' | 'boss'` 和 `bossWave?: number`。普通敌人的默认类型为 `normal`。Boss 死亡时增加 `bossesDefeated`，并沿用现有击杀、经验掉落、击杀回血和特效事件。

## 普通怪刷新节奏

普通怪基础刷新间隔使用：

```text
max(380, 1200 / (1 + elapsedMs / 120000))
```

这使前期仍逐渐加速，但无限后期最低保持 380 毫秒，不再下降到原来的 260 毫秒。

每只 Boss 登场时设置：

```text
bossSlowdownUntilMs = elapsedMs + 30000
```

当 `elapsedMs < bossSlowdownUntilMs` 时，普通怪刷新间隔乘以 `1.5`。Boss 缓冲只取最新一次登场的 30 秒窗口，不叠加倍率。

场上普通敌人数量上限为 `140`，Boss 不计入上限。达到上限后继续累计 `spawnTimerMs` 但不生成普通怪；数量下降后每帧最多补生成 4 只，避免一次性释放大量积压刷新。

## Boss 视觉与 HUD

Boss 使用明显大于普通敌人的轮廓：暗红核心、金色外缘、四枚旋转符钉和更宽的世界内生命条。`drawEnemy` 根据 `kind` 选择普通或 Boss 绘制，不创建独立美术资源。

新增 `boss-spawned` 战斗事件，携带坐标和轮次。`EffectRenderer` 为其生成大型金红召唤阵、短促镜头震动和扩散圆环。

HUD 在存在 Boss 时显示固定的 Boss 状态条，选择 `bossWave` 最大的存活 Boss，展示“第 N 劫”、当前生命和百分比。状态条不遮挡顶部生命、等级、击杀、累计时间和下一 Boss 倒计时；移动端允许换行。

## 数据流

`GameSimulation.update` 的顺序调整为：

1. 累计时间和冷却。
2. 生成所有到期 Boss。
3. 按节奏与数量上限生成普通怪。
4. 移动玩家和敌人。
5. 处理雷环、投射物、经验与死亡。
6. 只检查玩家死亡，不再检查胜利。

HUD 和 Phaser 场景只读取 `GameState`，不自行计算 Boss 轮次或刷新节奏。

## 测试

Vitest 覆盖：

- 经过五分钟后仍为 `playing`，不会进入胜利阶段。
- 五分钟生成第一只 Boss，十分钟生成第二只，边界更新不会重复生成。
- 一次更新跨越多个周期时不会漏掉 Boss。
- Boss 生命、伤害、速度和经验按轮次增长。
- Boss 死亡增加 `bossesDefeated`。
- 后期普通怪刷新间隔不低于 380 毫秒。
- Boss 登场后 30 秒内刷新间隔乘以 1.5，窗口结束后恢复。
- 普通怪达到 140 只后停止生成，Boss 仍可生成。

浏览器验证覆盖累计时间、下一 Boss 倒计时、Boss 世界绘制、Boss HUD 血条、死亡结算和移动端顶部 HUD 换行。控制台不得出现错误。

## 范围边界

本次只增加一种通用 Boss 模板，不加入 Boss 专属技能、阶段变化、远程弹幕、音效、Boss 掉落宝箱或新的升级项。
