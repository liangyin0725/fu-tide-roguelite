# 《符潮残夜》四技能、远程弹幕与主动技能设计规格

## 目标

本次更新提升角色和怪物的像素清晰度与战斗特效，在保留无限生存、每五分钟 Boss 和现有成长节奏的基础上，加入四被动流派限制、宝箱替换、远程小怪、可拦截弹幕、独立主动技能和可暂停的局内设置。

成功标准：

- 角色、普通怪和 Boss 在桌面与移动端均呈现清晰的像素轮廓，不因缩放发虚。
- 一局最多装备四个被动技能，普通升级不能突破上限，Boss 宝箱可以替换。
- 三种远程普通怪能形成可辨认、可躲避、可拦截的弹幕压力。
- 三个主动技能分别承担爆发、位移和防守，桌面及移动端均可操作。
- 设置页可暂停游戏并持久化选项，包括游戏速度。
- 后期敌人和特效数量受控，不破坏现有无限模式的稳定性。

## 非目标

- 不把游戏改造成完整双摇杆射击玩法。
- 不允许在设置页更换本局主动技能。
- 不重做现有 Boss 轮换、五分钟刷新规则或后期经验加速规则。
- 不增加账号、云存档、装备背包或局外养成。

## 四被动构筑

### 装备与升级

- 被动技能池由现有 16 种扩展至 20 种。
- 玩家最多装备四种被动技能，每种仍为 1 至 4 级，4 级觉醒。
- 未满四槽时，普通升级候选可以同时包含新技能和已装备技能。
- 满四槽后，普通升级只会提供这四种已装备技能的升级，不出现第五种技能。
- 已装备技能全部达到 4 级后，升级进入可重复的“悟道强化”，提供攻击伤害、最大生命、移动速度、拾取范围等基础属性选择，使无限模式仍可继续成长。
- HUD 始终显示四个固定被动槽；空槽、等级和觉醒状态必须一眼可辨。

### Boss 宝箱替换

- Boss 宝箱可以提供已装备技能强化，也可以提供未装备技能作为替换候选。
- 选择未装备技能后，界面先要求选择一个现有被动槽，再确认替换。
- 新技能从 1 级开始，被替换技能及其觉醒效果立即移除。
- 替换确认前可以返回宝箱候选，不允许误触后直接覆盖。
- 玩家属性改为“基础属性 + 当前四个被动贡献”的统一重算模型，替换后不得残留旧技能加成、计时器或特殊状态。

### 新增四种被动

1. **北斗星芒**：周期向八个方向发射星芒；等级提升伤害、频率与穿透。4 级觉醒“斗转星河”，形成两轮旋转星阵。
2. **破魔真炁**：击碎敌方弹幕时产生反击冲击；等级提升冲击伤害与范围。4 级觉醒“破魔回响”，冲击连锁附近敌人。
3. **聚灵玉**：缩短主动技能冷却；等级提高缩减比例。4 级觉醒“灵台不竭”，每次释放主动技能恢复护盾与少量生命。
4. **地煞钉魂**：攻击附加击退与短暂定身概率；等级提升触发率与控制强度。4 级觉醒“万魂镇岳”，周期定住附近普通怪，对 Boss 改为减速。

## 主动技能

### 选择与输入

- 每局开始时从三种主动技能中选择一种，主动槽独立于四个被动槽。
- 桌面端使用空格键释放，移动端使用固定尺寸的技能图标按钮。
- 主动技能显示当前图标、冷却遮罩和剩余秒数。
- 自动瞄准时，系统按技能规则选择最近或威胁最高的有效目标方向。
- 手动瞄准时，桌面根据指针相对角色的方向释放；移动端按住技能按钮拖动选择方向，松开释放，拖回取消区则取消。
- 无有效目标时，方向型技能沿角色最后移动方向释放；没有移动记录时使用默认向上方向。

### 三种技能

1. **万符归墟，进攻**：朝瞄准方向释放密集符剑并引爆，造成高额范围伤害。它不清除弹幕，也不提供护盾。
2. **乾坤挪移，机动**：向瞄准方向冲刺，冲刺期间短暂无敌，并摧毁路径上的敌方弹幕。位移终点限制在场地内。
3. **太极玄阵，防守**：以角色为中心展开持续结界，阻挡进入结界的敌方弹幕并减速敌人，伤害较低。

三个技能分别只有一个主要职责，避免“范围伤害加清弹”的同质化。技能冷却、持续时间和伤害使用独立配置，便于后续平衡。

## 远程小怪与敌方弹幕

### 敌人类型

- **弩妖**：保持中距离，攻击前显示狭窄瞄准线，约 2.4 秒发射一枚高速直线箭。
- **符咒师**：保持较远距离，攻击前显示扇形预警，约 3.6 秒发射五枚慢速扇形符弹。
- **引魂灯**：缓慢游走，攻击前闪烁灯火，约 4.5 秒发射一枚有限转向速度的追踪魂火；魂火追踪约 2.8 秒，玩家可绕行甩开。

远程怪随游戏时间逐渐加入普通刷怪池，占普通怪比例最高约 35%。它们使用与近战怪一致的后期刷怪减速规则。全场敌方弹幕设置硬上限；达到上限时远程怪延迟开火，不删除玩家眼前的既有弹幕。

### 弹幕模型

敌方弹幕独立于玩家飞剑和 `BossHazard`，至少包含类型、来源敌人、位置、速度、半径、伤害、剩余寿命及有限转向参数。远程怪死亡后，已发射弹幕继续存在到命中、被击碎或寿命结束，以保留攻击承诺。

每个弹幕更新帧的处理顺序固定为：

1. 移动与追踪转向。
2. 绕身剑轮接触拦截。
3. 太极玄阵范围阻挡。
4. 金光护体吸收伤害。
5. 玩家生命受伤与无敌帧。
6. 越界或寿命结束清理。

乾坤挪移在冲刺轨迹上额外执行弹幕击碎。金光护体拦截弹幕时按弹幕伤害扣除护盾；绕身剑轮等级越高，剑数与覆盖率越高。破魔真炁仅在弹幕被主动击碎或阻挡时触发，不因弹幕自然消失触发。

## 像素美术与特效

### 美术方向

- 采用已确认的“清晰 32px 符箓风”：强轮廓、有限色板、明亮技能边缘。
- 主角、近战怪、弩妖、符咒师和引魂灯使用独立 32px 逻辑尺寸位图帧；Boss 使用 48 至 64px 逻辑尺寸。
- 角色至少包含待机、移动、受击和施法状态；怪物至少包含移动、攻击预备、攻击和受击状态。
- 使用最近邻采样和整数倍优先缩放，摄像机与绘制位置进行像素对齐，避免亚像素模糊。
- 敌人通过轮廓、持有物和动画姿态区分，不能只依靠换色。

### 战斗反馈

- 普通攻击增加短拖尾、命中火花和短暂受击闪白。
- 弹幕击碎增加碎片、涟漪和独立音效。
- 4 级觉醒增加专属符文、边缘光和攻击形态变化，并保留现有大幅文字提示。
- 三个主动技能均有起手、持续和结束三个阶段的视觉反馈。
- Boss 预警层级始终高于装饰特效，不允许高亮粒子遮挡危险区域。
- 特效按“低、中、高”三档控制粒子数量、拖尾长度和屏幕闪光；碰撞范围与伤害规则不随特效档位改变。
- 对同时存在的粒子、伤害数字和残留贴花设置对象池与上限，超限时优先省略装饰效果。

## 设置与暂停

局内 HUD 增加齿轮图标。设置面板打开时，模拟时间完全停止，输入不传递给角色；关闭后恢复。设置使用本地存储持久化，缺失、版本过旧或数据损坏时回退到默认值。

设置项：

- 主动技能瞄准：自动 / 手动，默认自动。
- 游戏速度：0.75x / 1.0x / 1.25x，默认 1.0x。
- 音乐音量：0 至 100%，默认 70%。
- 音效音量：0 至 100%，默认 80%。
- 屏幕震动：开 / 关，默认开。
- 伤害数字：开 / 关，默认开。
- 特效强度：低 / 中 / 高，默认高。
- 移动端摇杆透明度：低 / 中 / 高，默认中；桌面端可以显示但注明仅移动端生效。

游戏速度统一缩放模拟增量，影响角色、敌人、弹幕、刷怪、主动与被动冷却、Boss 五分钟计时和游戏内生存时间。0.75x 下现实时间经过较慢，1.25x 下现实时间经过较快；菜单、设置界面及纯 UI 动画不缩放。切换速度立即生效，但设置页本身保持暂停。

## 架构与数据流

继续遵循现有分层：`src/sim` 负责确定性规则，Phaser 场景负责输入、绘制、音效和瞬时特效，HUD 控制器负责 DOM 界面。

建议拆分的规则单元：

- `loadout`：被动槽、候选池、悟道强化、宝箱替换事务和属性重算。
- `activeSkills`：技能定义、瞄准解析、冷却与释放结果。
- `enemyProjectiles`：远程攻击调度、弹幕运动、追踪、上限和拦截。
- `settings`：类型、默认值、版本化读取、校验和持久化。
- `pixelAssets` 或场景预加载模块：精灵表与动画注册，不包含战斗规则。

输入层把移动向量、主动技能释放请求和当前设置传入模拟；模拟返回状态和战斗事件；场景依据事件播放动画、音效、震动和粒子。升级、觉醒、宝箱、设置和失败界面均为暂停阶段，不推进敌人、弹幕、冷却或计时。

## 测试与验收

### 自动测试

- 第五种被动不能通过普通升级加入；满槽候选只来自现有四种。
- 宝箱替换需要明确选择旧槽，新技能为 1 级，旧技能属性与计时状态无残留。
- 四种新增被动的 1 至 4 级效果和觉醒事件正确。
- 全部四种被动觉醒后仍能获得悟道强化并继续升级。
- 三种远程怪按预警和冷却发射正确弹幕，远程怪比例与弹幕上限生效。
- 追踪魂火受最大转向速度限制，可以通过移动甩开。
- 剑轮、玄阵、护盾和玩家受伤严格遵循既定拦截顺序。
- 三个主动技能的方向、边界、无敌、伤害、清弹和冷却职责互不串用。
- 自动与手动瞄准在无目标、无移动记录和移动端取消操作时均有确定结果。
- 0.75x、1.0x、1.25x 对所有模拟计时使用同一倍率，UI 时间不受影响。
- 设置序列化、版本迁移、损坏回退和默认值正确。
- 暂停阶段不推进任何战斗模拟。

### 构建与视觉验收

- 运行完整单元测试与生产构建。
- 在桌面尺寸和约 390x844 的移动端尺寸实际游玩。
- 检查像素帧没有平滑模糊、文字和按钮不重叠、四被动槽与主动槽尺寸稳定。
- 检查手动瞄准、移动端拖放、设置暂停、速度切换和宝箱替换完整流程。
- 在后期高密度场景检查弹幕可读性、Boss 预警优先级、对象上限和帧率。
- 使用截图对比低、中、高特效档，确保低档仍保留所有关键攻击与预警信息。

## 实施边界

本规格可以作为一个连续实施计划，但应按“规则模型与测试、远程敌人与弹幕、主动技能、设置与 HUD、像素资源与特效、综合 QA”的顺序分阶段完成。任何平衡数值可以在测试与试玩中微调，但不能改变四槽上限、宝箱替换、三个主动职责、弹幕拦截顺序和游戏速度统一缩放这些已确认规则。
