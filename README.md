# 符潮残夜

一个基于 Phaser、TypeScript 与 Vite 制作的像素风肉鸽生存游戏。玩家在无尽怪潮中选择技能、强化、觉醒与天劫路线，并在局外洞府持续成长。

## 游戏内容

- 无限战斗：每 5 分钟出现劫主，后期以精英词缀、敌人编队和多段 Boss 战斗增加压力。
- 构筑成长：5 个技能栏、6 个强化栏、主动技能、宝箱替换与 6 级觉醒。
- 觉醒阵型：雷火、冰魂与钟镜组合会改变周身符咒的阵型和第三轮触发机制。
- 天劫与地图事件：每 5 分钟进行天劫抉择，并通过场景目标获得风险与收益。
- 局外洞府：角色天赋、道途节点、专属遗物与灵材锻炉均会持久化到浏览器本地存档。
- 内测模式：输入密码解锁后可预设技能、等级、主动技能与开局时间。

## 运行

需要安装 Node.js。

```powershell
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

打开 `http://127.0.0.1:5173/`。

Windows 下也可以直接双击 `start-game.cmd`。根目录的 `index.html` 是 Vite 源码入口，不能脱离本地服务器直接运行；若双击它，会显示正确的启动提示。

## 操作

- `WASD` 或方向键：移动
- 鼠标或设置页：选择自动/手动瞄准
- `Space`：释放主动技能
- 设置页：调整音量、瞄准方式与游戏速度

## 开发

```powershell
npm.cmd test -- --run
npm.cmd run build
```

核心战斗模拟位于 `src/sim/`，Phaser 场景和渲染位于 `src/scenes/`、`src/render/`，洞府持久化逻辑位于 `src/meta/`。

## 本地存档

局外数据保存在浏览器 `localStorage` 的 `fu-tide-dongfu-v1` 键中，包括道蕴、灵材、遗物锻造等级、遗物装备和角色解锁状态。
